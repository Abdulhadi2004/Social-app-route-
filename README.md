# SocialHub - Social Media App

A React-based social media application built with Vite, featuring user authentication, posts, comments, and profile management.

## Features

- **Sign up** - Create a new account
- **Login** - Sign in with email/username
- **Home** - View all posts in the feed
- **Post Details** - View post with all comments
- **Profile** - View user profile and posts
- **Create/Update/Delete Posts** - Full CRUD for posts
- **Create/Update/Delete Comments** - Full CRUD for comments
- **Change Password** - Update user password

## Tech Stack

- React 19 + Vite
- React Router
- Axios
- Tailwind CSS

## API

Uses the [Route Posts API](https://route-posts.routemisr.com/) (route-posts.routemisr.com).

## Setup

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

The app can be deployed to Vercel, Netlify, or any static hosting service.
